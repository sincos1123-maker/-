# 공룡시대 생존기 개선판

`index.html`을 내려받아 브라우저에서 열면 됩니다. 별도 설치가 필요 없습니다. 원본 파일은 변경하지 않았습니다.

## 개선한 부분

- 이름에 HTML 문자가 포함되어도 실행되거나 화면 구조가 바뀌지 않도록 처리했습니다.
- 이름, 진행 화면과 이전 기록, 의식주 선택, 네 가지 원리 체험 설정, 소감과 퀴즈 답을 브라우저에 자동 저장합니다. 새로고침 후 이어서 학습할 수 있습니다.
- 저장 공간을 사용할 수 없거나 저장 데이터가 손상된 경우에도 학습을 시작할 수 있도록 처리하고 상태를 표시합니다.
- 생존 점수에 의식주를 함께 반영합니다. 빠진 요소마다 옷 20점, 음식·물 20점, 잠잘 곳 40점을 차감합니다. 이는 교육용 모형이며 실제 생존 확률을 뜻하지 않습니다.
- 해설이 있는 복습 퀴즈 4문항을 추가했습니다. 답을 바꿔 복습할 수 있으며 결과는 현재 선택을 기준으로 기록합니다.
- 이름·선택·시대 방문 기록·퀴즈·소감을 텍스트 파일로 저장할 수 있습니다.
- 선택 상태를 보조기기에 전달하고, 화면 전환 시 제목으로 초점을 옮기며, 팝업의 키보드 초점을 제한합니다. 한글 입력 확정 중 Enter가 시작 버튼을 실행하지 않도록 했습니다.
- 단계 이름을 표시하고 좁은 모바일 화면에서 레이아웃을 조정했습니다.
- 외부 글꼴 요청을 제거했습니다. 그림과 체험은 HTML 안에 포함되어 인터넷 없이 사용할 수 있습니다. 출처 링크를 열 때는 인터넷이 필요합니다.
- 사람과 비조류 공룡의 공존, 불을 뿜는 공룡이 상상 설정이라는 설명을 추가했습니다.

## 검증

Chromium에서 전체 9단계 이동, 3개 선택 제한, 의식주 점수 분기, 팝업 Tab/Escape, 새로고침·이어하기, 시대 탭 Home/End, 4종 체험, 퀴즈 정오답·답 변경, 소감 유지, 결과 다운로드, 초기화, 손상된 저장 데이터와 저장 불가 상황을 확인했습니다. 320/375/768px 화면의 가로 넘침을 확인했고 정상 흐름에서 JavaScript 오류나 외부 리소스 요청은 없었습니다.

이 환경의 브라우저 정책은 file:// 직접 열기를 차단하므로, 파일을 직접 여는 방식의 검증은 수행하지 못했습니다. 로컬 HTTP 서버에서 검증했습니다. 최초 로드 후 네트워크를 끊어도 체험과 내장 사진이 작동했고, 팝업 중 새로고침 시 점수 중복 차감이 발생하지 않음을 확인했습니다. 다른 브라우저와 실제 보조기기에서의 동작은 검증하지 않았습니다.

## 저장 안내

학습 데이터는 이 기기의 브라우저 저장소에 보관되며 프로그램이 외부 서버로 전송하지 않습니다. 같은 기기·브라우저를 다른 사람이 사용하면 기록을 볼 수 있으므로 공용 기기에서는 학습 후 '처음부터'로 기록을 초기화하세요. 브라우저 설정·시크릿 모드·파일 위치 변경 등에 따라 저장이 제한되거나 이전 기록을 읽지 못할 수 있습니다. 보관할 기록은 마지막 화면에서 결과 파일로 저장하세요.
